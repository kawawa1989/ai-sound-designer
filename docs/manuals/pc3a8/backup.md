# PC3A8: ユーザーオブジェクトをバックアップする

## 目的

ユーザーが作った・編集したオブジェクト（テスト用 Program 1025〜など）を、USB メモリに .P3A ファイルとして保存します。
ROM の音色は対象にならず、保存する必要もありません（本文 13-6）。

いつ取るか:
- テスト用の Program を新しく保存したあと
- Master モードの **Reset** や Bootloader の **System Reset** の前（[recover.md](recover.md)）

## 前提

- USB メモリを用意している（空き容量は STORE ページの右上に出る。本文 13-6）
- 編集中の Program がない（Program モードに戻っている）

## 手順

1. 本体背面の **USB Storage** ポートに USB メモリを挿す（本文 13-1）
2. **Storage** モードボタンを押す。Storage モードのページが出る（本文 13-1）
3. 保存先に USB メモリ（USB Storage）を選ぶ。状態が ready になるのを待つ
   - **USBDrv**（PC につなぐ一時ドライブ）は選ばない。選ぶと USB-MIDI が切れる（本文 13-1）
4. **STORE** ソフトボタンを押す（本文 13-6）
5. 左の **Object Type** の一覧で **All types** を選び、**Select** を押す。左に * が付く（本文 13-7）
6. 右の **Range/Bank** の一覧で **Everything** を選び、**Select** を押す（本文 13-7）
   - 保存できるのは (u) の印がある範囲だけ（ユーザーのオブジェクトがある範囲。本文 13-7）
7. **Store** を押す
   - 「依存するオブジェクトも保存しますか」と出たら、保存する（本文 13-6）
8. 保存先のフォルダを選ぶ（本文 13-4）
9. ファイル名を入れて **OK** を押す。8 文字まで（例: `PC3A1114`）。拡張子 .P3A は本体が付ける（本文 13-6〜13-7）
10. Master ファイル（Master モードと MIDI モードの設定）も残すときは、Range/Bank の一覧の Master を選んで同じように保存する（本文 13-7）
11. **Exit** で Storage モードを抜け、USB メモリを抜く
12. .P3A ファイルを PC にもコピーし、保存日と中身（どの ID か）をメモする

## 確認

- USB メモリを PC で開くと、付けた名前の .P3A ファイルがある
- ファイルの日付が今日になっている（本体の時計で記録される。本文 11-17）

## 元に戻す

- バックアップを取るだけなので、本体の状態は変わらない
- 読み込む（LOAD）ときは [recover.md](recover.md) を見る。**OvFill・Overwrt の方式は使わない**（`docs/safety.md`）

## 注意

- **Storage モードの Format（USB メモリの初期化）を押さない**。USB メモリの中身が消える（本文 13-2）
- 保存の途中で USB メモリを抜かない
