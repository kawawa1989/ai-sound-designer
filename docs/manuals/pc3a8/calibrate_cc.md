# PC3A8: CC でキャリブレーション曲線を自動で測る

## 目的

値を手で変える代わりに、PC から CC（コントロールチェンジ）を送って LP Frq を動かし、曲線を自動で測ります。
手で値を合わせて Enter を押す作業（`docs/manuals/pc3a8/calibrate.md`）がなくなります。

CC は、Program のパラメータの制御元に割り当てた番号を送ると、演奏中にそのパラメータを動かします（本文 10-11）。
保存された値は変わりません。送ってよい CC と条件は `docs/safety.md` の「CC を送る条件」です。

## 前提

- `docs/pc3a8_setup.md` の接続で、`devices -s pc3a8` に MIDI 出力ポートと録音デバイスの `*` が付く
- Effect モードの Master Cmpr. が **Out**
- 下の「キャリブレーション用 Program 1026 を作る」が済んでいる（1 回だけ）

## キャリブレーション用 Program 1026 を作る（1 回だけ）

1. Program モードで **1025 KVA BASIC SAW** を選び、**Edit** で Program Editor に入る
2. **DSPCTL** ページで、左の列の **LP Frq** を **G 1（49 Hz）** にする（本文 6-29）
3. **DSPMOD** ページで、左の列の **LP Frq** を選び、▶ で右に移る（本文 6-30〜6-31）
   1. **Src1** を選び、数字ボタンで **14** を入力して **Enter** を押す。CC 14 が制御元になる（本文 10-11）。表示は「MIDI 14」などになる
   2. **Depth** を **10800 ct** にする
4. ほかの値は 1025 のまま変えない
5. **Save** で保存する。保存先は **1026** にし、ID を声に出して確かめる。1025 には上書きしない（本文 5-2〜5-4）
6. 名前を **KVA CC CAL** にする（名前の付け方は 1025 と同じ）

CC 14 が 0 のときカットオフは 49 Hz、127 のとき +10800 ct（9 オクターブ上の 25088 Hz）になる。
途中の CC で比例して動くかはマニュアルに書かれていないので、このあとの測定で確かめる。

## 手順

1. Program モードで **1026 KVA CC CAL** を選ぶ（Edit には入らなくてよい）
2. PC で実行する

   ```bash
   uv run synth-ai calibrate kva.dspctl.lp_frq -s pc3a8 --cc --conditions "1026 KVA CC CAL"
   ```

3. 「本体で 1026 KVA CC CAL を選んでいますか？」に **y** と答える。違う Program なら **n** で止める（何も送らない）
4. ツールが値ごとに CC 14 を送り、C4 を鳴らして録音・解析する。人の操作は要らない（1 点 4 秒ほど、9 点で 1 分弱）
5. 終わると CC 14 を 0 に戻し、曲線を `data/pc3a8_calibration/cc/` に保存する

## 確認

- 「注意: 値を上げても特徴が一方向に変わっていません」が出ていない
- 手動で測った曲線（`data/pc3a8_calibration/kva.dspctl.lp_frq__brightness_end.json`）と比べて、同じカットオフで明るさがほぼ同じ。
  比べた結果は `docs/pc3a8_parameter_table.md` の「CC での測定」に書く

CC の曲線は、手動の曲線と合うことを確かめるまでレシピに使わない（`cc/` に分けて保存しているのはこのため）。

## 元に戻す

- ツールは終わったとき・中断したとき（Ctrl-C）に CC 14 を 0 に戻す。戻ったか不安なら、Program を選び直す
- 1026 の保存された値は変わらない。測定のあとも保存しない

## 注意

- **1026 以外の Program を選んだまま実行しない**。ほかの Program でも CC 14 を制御元にしていれば、その音が変わる
- 送る CC は 14 だけ（sender が、許可した番号以外を送らない）
- 1026 を編集し直したら（LP Frq・Depth を変えたら）、`data/pc3a8_parameters/kva.json` の `cc_calibration` も同じ値に直す
