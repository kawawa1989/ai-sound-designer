# PC3A8: マスターエフェクトを確かめる

## 目的

録音・キャリブレーションの前に、Effect モードのマスターエフェクト（コンプレッサーと EQ）と Aux のオーバーライドが、
音を変えない状態かを確かめます。Program モードの音には、ここの設定が掛かります（本文 9-8）。

## 前提

- 確かめるだけで、**値は変えない**

## 手順

1. **Effect** モードボタンを押す
2. **MASTER** ソフトボタンを押す。Master Effects ページが出る（本文 9-8）
3. 次の項目を読む

   | 項目 | 期待する値（2026-11-14 の状態） |
   | --- | --- |
   | Mode | Master |
   | Order | Compressor ⇒ EQ |
   | Master FX | Master FX Enabled |

4. コンプレッサーの箱を選んで **Edit** を押し、**In/Out** が **Out** か確かめる。**Exit** で戻る（本文 9-8）
5. EQ の箱を選んで **Edit** を押し、各帯域の Gain と OutGain が **0.0 dB** か確かめる。**Exit** で戻る
6. **AUXFX1**・**AUXFX2** ソフトボタンを押し、それぞれ **Override** が **No** か確かめる（本文 9-5）
7. **Exit** で Effect モードを抜ける

## 確認

- すべて上の値なら、マスターエフェクトは音を変えない（`docs/pc3a8_setup.md` の「マスターエフェクト」）
- 違う値があったら、**変えずに**記録して相談する

## 元に戻す

- 値を変えていなければ、戻すものはない
- うっかり変えてしまったら、上の表の値に戻す。Aux のオーバーライドは、本体を再起動すると既定に戻る（本文 9-5）

## 注意

- **コンプレッサーが In だと、−28 dB を超える音が 3:1 で圧縮され、音量とエンベロープの測定がずれる**（`docs/pc3a8_setup.md`）
- Effect モードの設定は、マスターテーブルを保存すると電源を切っても残る（本文 9-4）。ツールからは変えない
