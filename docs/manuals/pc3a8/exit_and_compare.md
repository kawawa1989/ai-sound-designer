# PC3A8: 編集を保存せずに抜ける・Compare で比べる

## 目的

Program Editor で変えた値を、保存せずに捨てて抜けます。抜ける前に、編集前の音と聞き比べることもできます。
値を読むだけの作業、キャリブレーション、録音のあとは、いつもこの手順で終えます。

## 前提

- Program Editor に入っている（[program_editor.md](program_editor.md)）

## 手順

### 編集前の音と比べる（Compare）

1. Program Editor の中で **Storage** ボタン（モードボタンの 1 つ）を押す。Compare Editor になり、編集前の設定の音が鳴る（本文 6-13）
2. 鍵盤を弾いて、編集前の音を聞く
3. もう一度 **Storage** を押すと、Program Editor（編集後の音）に戻る

Compare Editor を使っても、今の編集は変わらない（本文 6-13）。

### 保存せずに抜ける

1. **Exit** を押す
2. 何か変えていれば「保存しますか」の画面（Exit ページ）が出る（本文 5-3）
   - **No**: 編集を捨てて Program モードに戻る ← **ふだんはこれ**
   - **Cancel**: 編集に戻る
   - **Yes**: 保存の画面に進む（保存するときだけ。[save_program.md](save_program.md)）
3. 何も変えていなければ、確認なしで Program モードに戻る（本文 5-3）

## 確認

- Program モードに戻り、Program を選び直したときに、いつもの音が鳴る

## 元に戻す

- **Yes** を押してしまっても、保存の画面で **Cancel** を押せば保存されない（本文 5-4）
- 保存してしまったら [recover.md](recover.md) の「テスト用の Program を保存し間違えた」

## 注意

- 編集中に別の Program を選んでも編集は捨てられる（本文 6-3）。ただし警告が出ないので、意図して捨てるときは Exit → **No** を使う
- Compare Editor にいる間に値を変えない（どちらの画面か分からなくなる）。戻ってから変える
