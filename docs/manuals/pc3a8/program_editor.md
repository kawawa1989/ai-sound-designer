# PC3A8: Program Editor の基本

## 目的

Program の値を見る・変えるための画面（Program Editor）の動き方を覚えます。
ほかの手順書（レシピの設定、キャリブレーション用 Program の作成）は、この操作を前提にしています。

## 前提

- Program モードで、編集する Program を選んでいる（例: **1025 KVA BASIC SAW**）
- 保存しない作業なら、最後に Exit で **No** を選ぶつもりでいる（[exit_and_compare.md](exit_and_compare.md)）

## 手順

1. **Edit** を押す。Program モードのランプが消え、**KEYMAP** ページが出る（本文 6-12）
2. 画面の下の段のソフトボタンでページを選ぶ（本文 6-12）
   - **大文字**のボタン（**ALG**、**DSPCTL**、**AMPENV** など）はページに移る
   - **大文字と小文字が混ざった**ボタン（**Save**、**Delete** など）は機能を実行する
   - 目的のボタンが見当たらなければ **more** を押す。ボタンの並びが切り替わる（今のページは変わらない）
3. カーソルボタン（▲▼◀▶）でパラメータを選ぶ。選んだ値が反転表示になる（本文 5-1）
4. 値を変える。次のどれでもよい（本文 5-1）
   - **Alpha Wheel** を回す
   - **−** / **+** ボタンを押す
   - 数字ボタンで入力して **Enter** を押す
5. **DSPCTL**・**DSPMOD** ページでは、次のように動く（本文 6-29〜6-31）
   1. **左の列**から機能（例: **LP Frq**、**Level**）を選ぶ
   2. **▶** で右側のサブページに移り、そこで **KeyTrk**、**VelTrk**、**Src1**、**Depth** などを変える
6. レイヤーが 2 つ以上ある Program では、**Chan/Layer** ボタンでレイヤーを切り替える（本文 6-12）。テスト用の Program は 1 レイヤー

このツールでよく使うページ（レシピの並び順）:

| ページ | 主に変えるもの | 出典 |
| --- | --- | --- |
| KEYMAP | Keymap（KVA では 999 Silence） | 本文 6-53 |
| ALG | Algorithm とブロックの機能（SAW、LOPASS など） | 本文 6-22〜6-23、6-54 |
| DSPCTL | LP Frq、Level などの基準の値 | 本文 6-29 |
| DSPMOD | Src1・Depth（何で動かすか、どれだけ動かすか） | 本文 6-30〜6-31 |
| ENV2 | フィルター用のエンベロープ | 本文 6-45 |
| AMPENV | 音量のエンベロープ | 本文 6-42〜6-44 |
| ENVCTL | AMPENV の速さの倍率 | 本文 6-45〜6-46 |
| COMMON | Monophonic など | 本文 6-35 |

## 確認

- 値を変えると、鍵盤を弾いた音がすぐ変わる（保存しなくても聞こえる。本文 5-1）
- 画面の上の段に、今のレイヤーとページが出ている

## 元に戻す

- 変えた値は覚えておいた元の値に戻すのが基本。分からなくなったら、Exit で **No**（[exit_and_compare.md](exit_and_compare.md)）

## 注意

- **編集中に Program を切り替えない**。保存していない編集は、警告なしで消える（本文 6-3）
- ALG ページでアルゴリズムやブロックの機能を回すと、音が大きく変わることがある（本文 6-22）。モニターの音量を下げておく
