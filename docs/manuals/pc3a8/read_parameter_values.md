# PC3A8: パラメータの値と範囲を画面で読み取る

## 目的

マニュアルに載っていない値（範囲・刻み・表示名）を、本体の画面で確かめます。
読み取った値は、パラメータ表 `data/pc3a8_parameters/kva.json` に記録します。

## 前提

- Program モードで、基準音 **1025 KVA BASIC SAW** を選んでいる
- モニターの音量を下げている
- **値を読むだけで、保存しない**。最後に必ず「保存しますか」で **No** を選ぶ

## 手順

1. **Edit** を押して Program Editor に入る
2. 読みたいページのソフトボタンを押す（例: **DSPCTL**、**DSPMOD**、**AMPENV**、**ENV2**）。ボタンが見当たらなければ **more** で切り替える（本文 6-12）
3. DSPCTL と DSPMOD では、次のように操作する（本文 6-29〜6-31）
   1. **左の列**から機能パラメータ（例: LP Frq、Level）を選ぶ
   2. **▶（右カーソル）**で右側のサブページに移る（KeyTrk、VelTrk、Src1、Depth など）
4. 値の範囲を調べるときは、Alpha Wheel で値を**最小・最大まで回す**。それ以上変わらないところが端の値。1 クリックで変わる量が刻み
5. 読んだら、**値を元に戻す**（下の「元に戻す」）
6. **Exit** を押し、「保存しますか」で **No** を選ぶ（本文 5-3）

## 確認

- Program モードに戻り、1025 を選び直したときに、いつもの音（ノコギリ波）が鳴る
- 心配なら、Exit の前に Program Editor で Storage ボタン（**Compare**）を押し、編集前の音と比べる（本文 6-13）

## 元に戻す

- 回した値は覚えておいた元の値に戻すのが基本。分からなくなっても、Exit で **No** を選べば編集はすべて捨てられる
- Program を選び直しても編集は捨てられる（本文 6-3）

## 注意

- **Yes（保存）を押さない**。押してしまったら、保存先の ID を確かめる。1025 なら基準音が変わるので、`docs/safety.md` の「基準音 1025 の設定」の値に戻して保存し直す
- **Replace は押さない**（ほかの ID に上書きしない）
- アルゴリズムやブロックの機能を回すと、音が大きく変わることがある（本文 6-22）
