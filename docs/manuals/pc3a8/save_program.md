# PC3A8: 編集した Program をテスト用 ID に保存する

## 目的

編集した Program を、テスト用の ID（1025 から）に新しく保存します。元の Program（ROM の音色や、ほかのテスト用 Program）は上書きしません。

## 前提

- Program Editor で編集が終わっている
- 保存先の ID を決めてある。`docs/safety.md` の「テスト用の領域」の表を見て、**まだ使っていない次の番号**にする
  （2026-11-14 時点で 1025〜1028 を使用中。次は 1029）
- 付ける名前を決めてある（例: `KVA ENVCTL CAL`）

## 手順

1. **Exit** を押す。「保存しますか」で **Yes** を押す（本文 5-3）。**Save** ソフトボタンを押してもよい
2. 保存の画面が出る。ID の欄を見る（本文 5-2、5-4）
   - 元が ROM の Program（例: 999 Default Program）なら、User Bank の空き ID（1025 から）が提案される
   - 元がメモリの Program（例: 1025）なら、**元と同じ ID が提案される**。このまま保存すると元が消えるので、必ず変える
3. ID を決めた番号にする。数字ボタンで入力して **Enter**、または Alpha Wheel で合わせる
   - **−** と **+** を同時に 2 回押すと、次の空き ID に移る（本文 5-2）
4. **Rename** を押して名前を付ける（本文 5-3）
   1. **<<<** / **>>>** でカーソルを動かす
   2. 文字のボタン（数字ボタンの下に文字が書いてある）を押して文字を入れる。同じボタンを続けて押すと次の文字になる
   3. **+/-** で大文字・小文字を切り替える。**Clear** で 1 文字消す
   4. **OK** を押す
5. 保存の画面に戻る。**ID を声に出して読み**、決めた番号か確かめる
6. **Save** を押す
   - 「置き換えます（Replace）」と出たら、その ID は使用中。**Replace は押さず**、**Cancel** を押して 3 からやり直す（本文 5-4）
7. `docs/safety.md` の「テスト用の領域」の表に、ID・名前・内容を書き足す

## 確認

- Program モードで、保存した ID を選ぶと、編集した音が鳴る。ID の前にひし形の印が付く（メモリの Program の印。本文 5-4）
- 元の Program（例: 1025）を選ぶと、元の音のまま鳴る

## 元に戻す

- 違う ID に保存してしまったら、その Program を消す（[recover.md](recover.md) の「テスト用の Program を保存し間違えた」）
- ROM の ID に保存してしまったら、新しいほうを消すと ROM の音色が戻る（本文 5-2、5-4）

## 注意

- **Replace を押さない**。メモリの Program を置き換えると、元は完全に消える（本文 5-4）
- **Program 999 Default Program と Setup 126 Internal Voices は変えない**（`docs/safety.md`）
- 保存したら、使った ID を必ず `docs/safety.md` の表に記録する。記録がない ID は「使っていない」とみなされ、上書きの原因になる
